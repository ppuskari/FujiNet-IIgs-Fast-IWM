# Project handoff - 2026-08-19

This repository starts the FujiNet IIgs Fast-IWM experiment series.

The immediate question is deliberately narrow:

> Can a IIgs and FujiNet reliably exchange SmartPort-style data using the
> IIgs IWM 2 us timing capability, with enough measured sustained payload
> margin to become a superior producer path for the existing DOC streamer?

Do not begin by changing radio networking, transcoding, Tool225, or DOC timing.
Prove the transport first.

The planned future payoff is a resident IIgs audio service whose Internet/TCP
work lives on FujiNet, leaving the 65816 responsible for burst reads, ring
management, and DOC servicing.  Existing CDA visualization should coexist with
that service rather than being replaced by it.
