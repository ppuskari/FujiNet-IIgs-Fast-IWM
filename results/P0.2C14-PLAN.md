# FASTIWM P0.2C14 plan

P0.2C13 proved that the IIgs host both programs IWM mode `$0F` and selects
the internal 3.5-inch IWM route (`$C031` bit 6 set), but it still received no
byte from the P0.2C12 one-microsecond-pulse transmitter.

P0.2C14 is a controlled transmitter-shape comparison:

- retain the P0.2C13 host route, exact IWM mode, ordering, and diagnostics;
- retain the private 2 MHz FujiNet SPI clock and 2 us falling-edge spacing;
- remove the P0.2C12 pulse-widening transform, restoring the encoder-native
  single SPI sample (0.5 us) for each RDDATA pulse;
- report live phase, EN35, DRIVE1, DRIVE2, and HDSEL state immediately before
  the private transfer;
- build both products from pinned clean sources and package them as one pair.

Expected FujiNet diagnostics include:

```
FASTIWM C14 TX SHAPE len=2139 cell=2us pulse=0.5us
FASTIWM C14 TX ROUTE phase=.. en35=. d1=. d2=. hdsel=.
```

Success requires the host to accept and validate the complete deterministic
512-byte packet. A timeout is still a useful result because it completes the
0.5 us versus 1 us pulse-width comparison under the now-proven host settings.
