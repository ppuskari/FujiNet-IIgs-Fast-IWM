# P0.2C11 — route direct IWM access to the internal controller

P0.2C10 proves the FujiNet arm survives for five seconds with zero reset
edges, but the IIgs never produces the expected `1011` READY phase. The 2 MHz
transmitter is therefore still not involved.

The missing prerequisite is the IIgs Slot register. The ROM SmartPort call
may restore `$C02D` before returning, while direct IWM access requires bit 6
clear so `$C0E0..$C0EF` select the internal Slot 6 IWM rather than external
Slot 6 hardware.

P0.2C11:

1. Saves `$C02D`, `$C031`, `$C036`, and the live IWM mode.
2. Selects internal Slot 6 and SmartPort, using the unconditional bank `$E1`
   I/O mirror.
3. Selects drive 1, prepares 2-us Read Data, and raises `1010 -> 1011`.
4. Restores the IWM mode and every saved IIgs register on all exits.
5. Adds a service-context phase poll on FujiNet in case an ESP32 GPIO edge is
   missed.
6. Retains a three-second delayed-send fallback, after the host has entered
   its long marker scan, and a ten-second abandoned-arm expiry.

Expected serial trace is either the direct path:

```text
FASTIWM C11 READY ARMED ...
FASTIWM C11 READY TRIGGER ... phase=0b
FASTIWM TX START ...
FASTIWM TX DONE ... err=0
```

or the bounded fallback path:

```text
FASTIWM C11 READY FALLBACK phase=..
FASTIWM C11 READY TRIGGER ...
FASTIWM TX START ...
FASTIWM TX DONE ... err=0
```
