# P0.2C acceptance

Hardware run sequence:

1. Serial monitor must show `FASTIWM ARM block=7fa55a` from the standard 4-us arm READBLOCK.
2. Host must report `ARM OK`.
3. Serial monitor must then show `FASTIWM REQ`, `FASTIWM TX START`, and `FASTIWM TX DONE` after the 1010 -> 1011 trigger.
4. Preferred host result is exact 512-byte payload PASS.
5. If the host times out while serial shows TX DONE, the remaining fault is isolated to the IIgs direct receive path rather than negotiation or FujiNet transmit.
