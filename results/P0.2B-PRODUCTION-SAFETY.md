# P0.2B production responder safety

The first responder draft called `spi_device_polling_transmit()` directly from the
phase GPIO ISR. P0.2B now explicitly avoids that.

Final execution model:

```text
GPIO phase ISR
  1110 -> arm + ACK low
  1111 -> set fast_iwm_probe_request only

systemBus::service()
  sees fast_iwm_probe_request
  deasserts ACK
  performs private 2 MHz SPI transmit
  asserts ACK
  returns
```

The blocking transmit therefore runs in FujiNet bus-service context, matching the
normal SmartPort architecture more closely. The ISR remains limited to phase-state
latching and GPIO ACK manipulation.

Production FujiApple Rev1 uses upstream runtime hardware detection. These override
flags remain disabled:

```text
REV1DETECT
MASTERIES_REV0
MASTERIES_REVAB
NO3STATE
```
