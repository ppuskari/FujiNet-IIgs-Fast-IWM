# P0.2D0 — live DOC PCM streamer

P0.2C19 proved 32 exact 512-byte packets at 35,108 encoded bytes/sec. P0.2D0
turns that transport into an arbitrary 8-bit PCM path and runs the frozen
Tool225 DOC double-buffer engine concurrently at 21,972.65 samples/sec.

## Wire codec

- Each physical IWM byte retains bit 7 set.
- Seven PCM bytes contribute seven low-7-bit bytes.
- An eighth byte packs the seven PCM MSBs.
- One 512-byte physical packet therefore carries 448 arbitrary PCM bytes.
- The deterministic hardware waveform is unsigned byte values 1 through 255
  repeating. It exercises both PCM MSB states and never emits DOC terminator 0.

## Hardware run

- One standard 4-us READBLOCK `$7FA55A` arms 240 packets.
- 240 × 512 = 122,880 physical bytes.
- 240 × 448 = 107,520 verified PCM bytes (4.893 seconds at the DOC rate).
- The IIgs starts Tool225 after packet 96: 43,008 PCM bytes are committed.
- Tool225 preloads its 32 KiB audible DOC ring, leaving 40 source blocks of
  initial lead, then refills 16 KiB halves while foreground IWM receive runs.
- A locked 128 KiB source ring is initialized to unsigned `$80` silence.
- The host fails on decoded-byte mismatch, transport timeout, Tool225 error,
  or if the exported Tool225 source counter catches the producer.

## Pass criteria

The screen must show both:

```
FAST PCM PASS: 240 packets / 107520 bytes verified.
DOC PLAY PASS: 21973 Hz drain complete, no underrun.
```

Useful PCM bytes/sec must exceed 21,973, `underrun=$0000`, and the serial log
must end with:

```
FASTIWM TX DONE packet=239 ... err=0
FASTIWM D0 PCM BURST DONE packets=240 encoded=122880 pcm=107520
```
