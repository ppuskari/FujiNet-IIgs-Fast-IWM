# P0.2B FujiNet hardware target

Hardware confirmed by Petar: FujiNet Apple Rev 1.

Current FujiNet upstream represents the early Rev1 Apple hardware as the
`fujiapple-rev0` software target with `REV1DETECT` enabled. P0.2B therefore
uses exactly these build selectors:

```text
BUILD_APPLE
IWM
fujiapple-rev0
PINMAP_A2_REV0
REV1DETECT
IIGS_FAST_IWM_PROBE
```

No `MASTERIES_*` or `NO3STATE` flag is added unless later hardware evidence
requires it.

The ordinary SmartPort transmitter stays at upstream 1 MHz. The private
FASTPROBE responder alone gets the additional 2 MHz transmit handle.
