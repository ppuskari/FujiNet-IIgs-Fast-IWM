# P0.2B FujiNet hardware target

Hardware confirmed by Petar: FujiNet Apple Rev 1 production hardware.

Important distinction: this board is **not** one of the special early
preproduction Rev1 units that require `REV1DETECT`.

Pinned FujiNet upstream already detects normal production Rev1 hardware at
runtime. Its normal Apple path probes the Rev1 hardware-detection signals,
sets `a2hasbuffer` / `a2no3state` as appropriate, selects the Rev1 safe-reset
GPIO, and records the detected hardware version.

P0.2B therefore uses these build selectors:

```text
BUILD_APPLE
IWM
fujiapple-rev0
PINMAP_A2_REV0
IIGS_FAST_IWM_PROBE
```

Intentionally **not** enabled:

```text
REV1DETECT
MASTERIES_REV0
MASTERIES_REVAB
NO3STATE
```

`REV1DETECT` is reserved for the small number of early preproduction Rev1
boards that predate the proper hardware-detection pull-up. It must not be
used for this production Rev1 test board.

The ordinary SmartPort transmitter stays at upstream 1 MHz. The private
FASTPROBE responder alone gets the additional 2 MHz transmit handle.
