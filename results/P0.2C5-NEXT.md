# P0.2C5 next hardware test

Build and flash only `fujinet-p0.2c5-firmware.bin` at application offset `0x10000`.
Keep using the existing `FASTPROBE-P0.2C.po` host image.

Expected serial split:

```text
FASTIWM C4 AUTO TX START ...
FASTIWM C5 BUS ACQUIRE START
```

If no `BUS ACQUIRE DONE` follows, the second SPI device cannot obtain the bus after the SmartPort arm transaction.

If `BUS ACQUIRE DONE ret=0` appears but no `BUS RELEASE`, the hang is inside `spi_device_polling_transmit(spifast, ...)`.

If `BUS RELEASE ret=0` and `AUTO TX DONE err=0` appear, the bus-arbitration fix worked and the 2-MHz waveform was physically emitted.
