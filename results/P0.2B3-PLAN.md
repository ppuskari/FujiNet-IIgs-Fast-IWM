# P0.2B3 — enable IWM Read-Data state

P0.2B2 successfully bypassed the ACK gate and issued the direct private request, but the IIgs timed out waiting for a valid IWM byte.

The Apple IIgs Hardware Reference makes the missing host condition explicit: the IWM Read-Data register is selected by Q6=0, Q7=0 **with the spindle/drive-enable state ON**. P0.2B2 selected Q6=0/Q7=0 but never accessed `$C0E9` (drive enabled), so it was not guaranteed to be reading the Data register at all.

P0.2B3 is host-only. It reuses the already-flashed P0.2B2 FujiNet firmware unchanged.

Sequence:

1. Enter private phase `1110`.
2. Access `$C0E9` to enable the IWM spindle/drive state.
3. Read IWM Status and save it for diagnostics. Status bit 5 should indicate whether a drive is selected/enabled.
4. Select Q7=0/Q6=0.
5. Raise PH0 to private request `1111`.
6. Poll the IWM Read-Data register for marker `$D5 $AA $96` and the deterministic 512-byte payload.
7. On all exits, pulse private/reset phase cleanup and access `$C0E8` to disable the drive state.

The observed idle mode `$0C` already has mode bit 2 set, so the one-second motor-off timer is disabled and cleanup should be immediate.
