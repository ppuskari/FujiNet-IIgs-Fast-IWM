# Results

Check in concise, reproducible result summaries here.

Suggested naming:

`E1-ROM3-2.8MHz-4us-YYYYMMDD.md`

`E1-TWGS-14MHz-4us-YYYYMMDD.md`

`E3-ROM3-2.8MHz-2us-YYYYMMDD.md`

Raw serial/debug logs should go under `results/local/` and remain ignored until
there is a reason to preserve them.
