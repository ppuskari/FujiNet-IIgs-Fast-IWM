# P0.2D3: IIgs-configured provider endpoint

P0.2D3 removes the hidden dependency on FujiNet's persisted NetStream
configuration while retaining P0.2D2's reset-free 16 KiB batch return.

The IIgs application uses the same endpoint interaction as the established
22-mono EthernetStreamer:

- provider host default: `192.168.5.235`
- provider TCP port default: `22510`
- blank input accepts each default
- a DNS name/IP and port can be entered at launch
- Escape cancels before starting the stream

FASTPROBE sends a 512-byte `D3EP` configuration record with SmartPort
WRITEBLOCK `$7FA556`. FujiNet validates and stores the endpoint in RAM, then
READBLOCK `$7FA559` starts the provider connection. Firmware also compiles the
same default endpoint as a fallback, so no FujiNet web or SD configuration is
required.

The normal provider status, 16 KiB ready threshold, 32-packet 2 us burst,
512 KiB Tool225 ring, and 21,973 Hz DOC playback path remain unchanged.
