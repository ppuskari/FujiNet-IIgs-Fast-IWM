# P0.2C19 — 16 KiB sustained 2 µs burst benchmark

P0.2C18 is the first hardware-verified exact 512-byte 2 µs transfer. P0.2C19
keeps that byte receiver and measures the next risk before DOC audio is added:
whether the matched IIgs/FujiNet link can repeatedly produce a full streamer
buffer quantum faster than it would be consumed.

## Protocol

- One standard 4 µs SmartPort READBLOCK `$7FA55A` arms the experiment.
- The host selects the proven internal-IWM/3.5-inch route and exact mode `$0F`.
- The host requests 32 consecutive packets with a 1010-to-1011 READY edge.
- Each packet contains marker `$D5 $AA $96` and 512 bytes generated as
  `$80 | ((byte_index + packet_index) & $7F)`.
- After each packet the host drops READY to 1010, enables interrupts, and
  validates all 512 bytes. FujiNet re-arms only after observing READY low.
- The host disables interrupts again immediately before the next READY edge.
- After packet 32, all IWM and IIgs routing/speed state is restored exactly.

## Measurement

The 60 Hz GetTick window covers route/mode setup, all physical packets,
per-packet validation, and state restoration. The harness reports:

- completed 512-byte packets;
- validated bytes;
- elapsed ticks;
- validated bytes/second;
- validated kbit/second.

The burst is 16,384 bytes, so the rate numerator is `16,384 * 60 = $000F0000`.
The minimum streamer gate is sustained validated throughput above the actual
DOC rate of 21,973 bytes/second. The amount above 21,973 is the available
playback and scheduling margin for the next phase.
