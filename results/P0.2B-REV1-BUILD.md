# P0.2B Rev1 exact build gate

This commit exists to run the exact FujiApple Rev1 firmware workflow after
that workflow became available on the default branch.

Required compile flags:

```text
REV1DETECT
IIGS_FAST_IWM_PROBE
```

The resulting firmware artifact must contain at least `firmware.bin`,
`bootloader.bin`, and `partitions.bin` before hardware deployment.
