# P0.2B production Rev1 build gate

This gate builds the confirmed FujiApple production Rev1 configuration.

Required experiment flag:

```text
IIGS_FAST_IWM_PROBE
```

The normal FujiNet Apple target remains:

```text
BUILD_APPLE
IWM
fujiapple-rev0
PINMAP_A2_REV0
```

The following overrides must remain disabled for this board:

```text
REV1DETECT
MASTERIES_REV0
MASTERIES_REVAB
NO3STATE
```

Production Rev1 hardware is detected by the normal runtime hardware-detection
path in pinned upstream firmware.

The resulting firmware artifact must contain at least `firmware.bin`,
`bootloader.bin`, and `partitions.bin` before hardware deployment.
