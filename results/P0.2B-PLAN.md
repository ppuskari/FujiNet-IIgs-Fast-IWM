# P0.2B hardware acceptance criteria

The first private Fast-IWM wire run is successful enough to continue if all of the following hold:

1. FASTPROBE observes the idle IIgs IWM fast bit already set.
2. FujiNet recognizes private phase `1110` and asserts ACK.
3. Raising PH0 to `1111` causes a deterministic private 2 us transmit packet.
4. The IIgs locates marker `$D5 $AA $96` through direct IWM data-register polling.
5. The first 512-byte payload validates against `$80 | (index & $7F)` with no mismatches.
6. The 256-packet run completes without timeout and reports throughput.
7. Exiting FASTPROBE resets the SmartPort bus and GS/OS can access normal FujiNet volumes again.

Performance is secondary to correctness on the first P0.2B run. Once the 2 us path is reliable, P0.2C will reduce per-packet overhead and move toward an exact 16 KiB producer burst.
