# P0.2B paired production release workflow

The `fastiwm-p02b-release.yml` workflow builds the matching IIgs FASTPROBE disk and FujiNet firmware from one pull-request head. It enforces production Rev1 runtime detection by rejecting accidental `REV1DETECT`, `MASTERIES_*`, or `NO3STATE` overrides, and checks that the blocking 2 MHz transmit is not called from the GPIO phase ISR.
