# P0.2C10 — immediate live-C READY and persistent arm

P0.2C9 hardware proved that FujiNet decodes `$7FA55A` and arms the matched
firmware, but no `READY TRIGGER` follows. Therefore the 2 MHz transmitter is
not yet involved: the host-ready `1011` edge was either never reached or the
armed latch was cleared first.

P0.2C10 closes both paths:

1. The host uses the saved live IWM mode immediately when C=`1`. The observed
   `$0C` already has 2 µs cell timing, so H/L do not need to reach exact `$0F`
   before READY.
2. FujiNet preserves the arm across every `0101` ROM cleanup reset instead of
   only the first one.
3. A five-second service-context deadline expires an abandoned arm safely.
4. The host still attempts bounded `$0F` programming if the live C bit is not
   set, and still refuses to trigger a 2 µs packet without C=`1`.

Expected new trace:

```text
FASTIWM C10 READY ARMED ...
FASTIWM C10 READY TRIGGER ... phase=0b held_resets=N
FASTIWM TX START ...
FASTIWM C5 BUS ACQUIRE DONE ret=0
FASTIWM TX DONE ... err=0
```
