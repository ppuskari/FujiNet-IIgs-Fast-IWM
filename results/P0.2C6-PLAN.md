# P0.2C6 — immediate delayed-packet host receive

P0.2C4 proved that FujiNet recognizes the magic arm block `$7FA55A`, schedules the 2 MHz transmit, starts it, and returns successfully with `err=0`. The observed transmit duration is about 9 ms.

P0.2C5 added the corrected Apple IIgs IWM Read Data register selection (`DRIVE ENABLED`, `Q7=0`, `Q6=0`) but still timed out.

P0.2C6 removes two remaining host-side hazards without changing FujiNet firmware:

1. No TextTools output occurs between the standard SmartPort arm call returning and direct IWM polling.
2. The obsolete manual `1010 -> 1011` request transition is removed. P0.2C4 delayed autosend no longer requires it.

The host therefore enters IWM Read Data state as quickly as possible after the 4 us arm reply completes and waits for the existing C4 delayed packet.
